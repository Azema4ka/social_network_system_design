# social_network_system_design
System Design социальной сети для курса по System Design.

## Функциональные требования
- Пользовательский профиль:
- - Подписка/Отписка;
- - Просмотр профиля;
- Пост:
- - Публикация;
- - Прикрепить фотографии;
- - Оставить описание;
- - Отметить гео место;
- - Лайк/Дизлайк
- - Оставить комментарий;
- Поиск:
- - По гео местам и отображение связанных постов;
- Лента постов:
- - Просмотр ленты на основе подписок в обратном хронологическом порядке;
- - Лента других путешественников;
- - Своя лента;
- Референс https://pognali.ru/

- - Поиск:

- Работу с помощью мобильных устройств и браузер
- Одновременных соединений: 10% от DAU = 1 000 000
- SLO
- - Доступность: 99,9 =+- 8,7ч за год
- Сезонность - лето и зима
- Данные храним всегда
- Ограничения:
- - Загрузка фотографий не больше 1,5МБ (Full HD)

## Ограничения
- Максимум фотографий в посте - 20
- Максимум размер одной фотографии - 5 МБ (FullHD)
- За 1 раз в ленте выгружаются постов - 12

## Модели данных
### Профиль (980 kB)
- id: uuid (16 bytes)
- first_name: varchar(32) (128 bytes)
- last_name: varchar(32) (128 bytes)
- age: smallint (2 bytes)
- region: char(2) (2 bytes) (ISO 3166-1 Alpha-2)
- city: varchar(256) (1 024 bytes)
- description: varchar(512) (2 048 bytes)
- photo: bytes(1000000) (1 000 000 bytes) (photo 800x800px)

### Пост (100 mB)
- id: uuid (16 bytes)
- author_id: uuid (16 bytes)
- title: varchar(256) (1 024 bytes)
- description: varchar(2 048) (8 192 bytes)
- photos: 100 000 000 bytes (5000000 bytes * 20)
- coordinates: bigserial (8 bytes)
- count_likes: integer (4 bytes)
- count_dislikes: integer (4 bytes)

### Пост для ленты (5 mB)
- id: uuid (16 bytes)
- title: varchar(256) (1 024 bytes)
- preview: 5 000 000 bytes (5000000 bytes)
- coordinates: bigserial (8 bytes)
- count_likes: integer (4 bytes)
- count_dislikes: integer (4 bytes)

### Комментарий (8 kB)
- id: uuid (16 bytes)
- author_id: uuid (16 bytes)
- description: varchar(2 048) (8 192 bytes)

## Расчёты нагрузки
### Профиль
Просмотр профиля
```
Чтение RPS: 579 ~= 10 000 000 * 5 / 24 / 60 / 60
Чтение трафик: 554mB/s ~= 579 RPS * 980 kB
```

Подписки на профиль
```
Запись RPS: 232 ~= 10 000 000 * 2 / 24 / 60 / 60
Запись трафик: 4000 b/s ~= 232 RPS * 16 bytes (profile_id)
```

Отписки от профиля
```
Запись RPS: 116 ~= 10 000 000 * 1 / 24 / 60 / 60
Запись трафик: 2000 b/s ~= 116 RPS * 16 bytes (profile_id)
```

### Посты
Публикация поста
```
Запись RPS: 232 ~= 10 000 000 * 2 / 24 / 60 / 60
Запись трафик: 23 200 mB/s ~= 232 RPS * 100 mB
```

Реакция на пост (лайк или дизлайк)
```
Запись RPS: 1 158 ~= 10 000 000 * 10 / 24 / 60 / 60
Запись трафик: 23 160 b/s ~= 1 158 RPS * (4 bytes + 16 bytes) (like/dislike + post_id)
```

Оставить комментарий
```
Запись RPS: 463 ~= 10 000 000 * 4 / 24 / 60 / 60
Запись трафик: 3 704 kB/s ~= 463 RPS * 8 kB
```

Просмотр постов в ленте
```
Чтение RPS: 4 630 ~= 10 000 000 * 40 / 24 / 60 / 60
Чтение трафик: 278 000 mB/s ~= 4 630 RPS * 5 mB * 12 (пагинация)
```

### Поиск
Поиск профиля
```
Чтение RPS: 232 ~= 10 000 000 * 2 / 24 / 60 / 60
```

Поиск мест
```
Чтение RPS: 348 ~= 10 000 000 * 3 / 24 / 60 / 60
```
